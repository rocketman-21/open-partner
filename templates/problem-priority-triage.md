## Problem Types

- Need: users do not care enough.
- Product: product does not solve the need.
- Activation: users do not reach value.
- Retention: users do not return.
- Growth: happy users exist but acquisition is weak.
- Sales: prospects do not advance.
- Pricing: value exists but price is unclear.
- Runway: not enough time or cash.
- Team: founder/team issue slows execution.

## Ranking Questions

1. Which problem can kill the company soonest?
2. Which problem blocks the most learning?
3. Which problem, if solved, makes everything else easier?
4. Which problem can be tested fastest?
5. Which problem are we avoiding?
