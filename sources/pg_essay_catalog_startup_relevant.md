# Paul Graham Essay Catalog — Startup-Relevant Seed Set

The full PG index currently contains a long list of essays. This seed set prioritizes essays that matter for YC-style office hours.

## P0: Core to every mock office-hours session

| Essay | Why it matters | Use in office hours |
|---|---|---|
| Do Things that Don't Scale | Manual user acquisition, concierge onboarding, high-touch service, narrow initial markets. | Turn vague growth goals into concrete unscalable actions. |
| Startup = Growth | Defines startups by fast growth; explains growth as the compass for decisions. | Diagnose whether the company is actually operating like a startup. |
| Startups in 13 Sentences | Compact rules: cofounders, launch, users, metrics, frugality, morale. | Quick checklist for recurring founder behavior. |
| How to Start a Startup | Good people, build what customers want, spend little. | Foundational triage: team, product, burn. |
| What I've Learned from Users | YC value: focus, speed, individualized advice, colleagues, weekly measurable action. | Design the mock YC office-hours loop. |
| Default Alive or Default Dead? | Runway and profitability trajectory. | Decide whether the session is about ambition or survival. |
| How Not to Die | Stay in motion, avoid demoralization, keep external accountability. | Rescue stalled companies. |
| How to Get Startup Ideas | Live in the future, solve your own or adjacent users' real problems. | Evaluate idea quality and founder insight. |

## P1: Fundraising and investor readiness

| Essay | Why it matters | Use in office hours |
|---|---|---|
| How to Raise Money | Fundraising process and founder psychology. | Build fundraising plan only when traction/story supports it. |
| How to Convince Investors | Investors are convinced by a startup that is actually doing well. | Convert narrative work into traction work. |
| A Fundraising Survival Guide | Surviving the fundraising process. | Minimize distraction and preserve runway. |
| High Resolution Fundraising | Incremental close strategy. | Structure seed raises and avoid all-or-nothing closes. |
| The Equity Equation | How to think about equity compensation. | Hiring and cofounder equity decisions. |
| The Hacker's Guide to Investors | Investor/founder incentives. | Avoid being manipulated by financing mechanics. |

| Essay | Why it matters | Use in office hours |

| The Hardest Lessons for Startups to Learn | Hard truths: release early, listen, don't overbuild. | Identify resistant founder behaviors. |

## Refreshing this catalog

Run `scripts/build_pg_manifest.py` locally to parse the full PG essay index into JSON/Markdown. The script is metadata-first and does not commit full article text by default.
