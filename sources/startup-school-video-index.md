# Startup School Video Index

Last updated: 2026-05-12

Primary source: https://www.ycombinator.com/blog/startup-school-videos

YC says the public Startup School videos are 15-30 minute talks by YC Group Partners on recurring founder questions. This index links to the official announcement and the YouTube videos listed there.

## How To Use This Index

- Before a session about users, use the user-talk and first-customers videos.
- Before a session about MVP, use the MVP and launch videos.
- Before a session about pricing or revenue, use the pricing video.
- Before a session about team issues, use the co-founder relationships video.
- Before a session about YC application, use Dalton Caldwell's application talk.
