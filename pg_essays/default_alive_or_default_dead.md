# Default Alive or Default Dead?

## Definition

A startup is default alive if, assuming current expenses and recent revenue growth continue, it reaches profitability before running out of money. It is default dead if it does not.

## Why it matters

The rest of the office-hours conversation depends on this answer.

- If default alive: discuss ambition, growth, hiring, and larger opportunities.
- If default dead: discuss survival, fundraising reality, expense cuts, monetization, and plan B.

## Inputs needed

- Cash in bank
- Monthly burn
- Monthly revenue
- Revenue growth rate over last 3 months
- Gross margin
- Committed expenses
- Expected fundraising timeline
- Hiring plan

## Fatal pinch

Default dead + slow growth + not enough time to fix it.

## Office-hours questions

1. Are we default alive or default dead?
2. If default dead, when exactly do we hit the fatal pinch?
3. What needs to change: revenue, burn, growth rate, or financing?
4. What is plan B if fundraising fails?
5. When do we switch from plan A to plan B?
6. Are we hiring because growth demands it, or because hiring makes us feel like a real company?

## Practical rule

Never say "we can always raise" without writing down the survival plan if you cannot raise.
