# Knowledge Base Maintenance

## After every office-hours session

- Update `templates/session-summary.md`.
- Add decision to `templates/decision_log_template.md`.
- Update `templates/metrics_dashboard.md`.
- Add user insights to `playbooks/user_learning_pipeline.md` log.
- Update company snapshot if facts changed.

## Weekly

- Archive weekly update.
- Re-rank top risks.
- Mark completed experiments.
- Add one new source summary if relevant.

## Monthly

- Review whether advice is getting more specific.
- Delete stale assumptions.
- Recalculate default-alive/dead.
- Revisit one-liner and ICP.
