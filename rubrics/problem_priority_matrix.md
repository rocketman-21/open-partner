# Problem Priority Matrix

Use this to decide what matters most right now.

Score each problem 1-5.

| Dimension | Question | Score |
|---|---|---:|
| Kill risk | Will this kill the company if ignored? | |
| Leverage | If solved, does it unlock major progress? | |
| Time-to-feedback | Can we learn within a week? | |
| Founder control | Can founders directly affect it? | |
| Evidence strength | Do we have evidence this is real? | |
| Compounding | Will solving it compound growth/learning? | |

## Priority score

`priority = kill risk + leverage + time-to-feedback + founder control + evidence strength + compounding`

## Problem classes

### P0: Immediate survival

- Running out of money.
- Cofounder collapse.
- No product/useful thing shipped.
- No users and no path to users.

### P1: Main growth/product bottleneck

- Weak activation.
- Weak retention.
- Wrong ICP.
- No pricing/sales clarity.
- Product not sufficiently useful.

### P2: Important but not this week

- Hiring.
- Partnerships.
- Brand polish.
- Fundraising narrative if not fundraising.
- Infrastructure scaling before usage.

### P3: Distractions

- Conferences without targets.
- Awards/press without users.
- Cosmetic rebrands.
- Overbuilt dashboards.
- Legal/company mechanics beyond current need.

## Office-hours rule

If there is a P0 problem, do not spend the session on P2/P3 topics.
