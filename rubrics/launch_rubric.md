# Launch Rubric

## Good launch

- Targets a specific user segment.
- Gets users to a value moment.
- Produces feedback within days.
- Can be followed by manual onboarding.
- Measures activation/retention, not just attention.

## Weak launch

- Broad audience, vague ask.
- Optimized for press instead of users.
- No follow-up system.
- No success metric.
- Delayed for polish unrelated to learning.
