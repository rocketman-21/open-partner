# Metrics Quality Rubric

Score each metric 0-2.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| User value | Vanity | Indirect | Directly tied to value |
| Repeatability | One-time | Occasional | Repeated behavior |
| Actionability | Does not change decisions | Sometimes useful | Clearly changes next action |
| Specificity | Vague | Somewhat defined | Precisely defined |
| Stage fit | Too advanced/irrelevant | Partly useful | Matches current bottleneck |

## Interpretation

- 0-4: likely vanity metric.
- 5-7: useful supporting metric.
- 8-10: strong candidate for key metric.
