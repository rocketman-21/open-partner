# Case Study: Stripe and Founder-Led Installation

## Why this matters

Stripe is used as an example of aggressive early user acquisition. The pattern is not merely selling; it is collapsing the time between interest and activation.

## Pattern

- User says yes to trying the product.
- Founder does not wait or send a passive link.
- Founder helps the user get set up immediately.
- Activation friction becomes visible to the founder.
- Product and onboarding improve because founders personally watch the process.

## Mock-office-hours questions

- What is our version of "give me your laptop"?
- When a user agrees to try it, what still prevents activation?
- Can a founder personally remove that friction now?
- Are we hiding behind onboarding automation because activation is uncomfortable?

## Action template

For every interested user this week, we will schedule a setup call within 24 hours and personally get them to first value.
