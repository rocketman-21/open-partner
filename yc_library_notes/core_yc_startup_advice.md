# YC Startup Library Notes: Essential Startup Advice

## Core principles

- Launch now.
- Build something people want.
- Do things that do not scale.
- Find simple 90/10 solutions.
- Find 10-100 customers who love your product.
- Pick one or two key metrics.
- Default to action and learning.

## How to use in office hours

Ask which principle is currently being violated.

Examples:

- Not launched -> launch fast / MVP.
- No intense users -> narrow segment / talk to users.
- No growth -> manual acquisition / metric selection.
- Too many features -> 90/10 solution.
- Vanity metrics -> choose behavior-based metric.

## Session prompt

Which essential YC rule are we currently avoiding because it is uncomfortable?
