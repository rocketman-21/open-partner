# YC Startup Library Notes: Analytics and Metrics

## Core idea

Analytics should answer founder decisions. Do not build a dashboard for its own sake.

## Useful early metrics

- Activation rate.
- Time-to-value.
- Retention/repeat usage.
- Paid conversion.
- Revenue per customer.
- Sales cycle length.
- Churn reason.
- Referral rate.

## Dangerous metrics

- Raw signups.
- Pageviews.
- Downloads.
- Impressions.
- Community size without usage.
- Gross transaction volume disconnected from durable value.

## Metric quality test

A good metric changes what you do next.
