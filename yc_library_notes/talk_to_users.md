# YC Startup Library Notes: Talking to Users

## Core idea

Talking to users is not pitching. It is gathering evidence about real behavior, pain, workarounds, urgency, and willingness to change.

## Bad user research

- Asking if they like the idea.
- Asking hypothetical willingness to pay.
- Talking only to friends.
- Searching for compliments.
- Ignoring what users actually do.

## Better user research

- Ask about the last time the problem happened.
- Ask what they did and why.
- Ask what they have tried before.
- Ask what happens if the problem remains unsolved.
- Watch them use the product.
- Ask for commitment, not just opinion.

## Office-hours check

If no users were spoken to since last session, the next action is probably not strategy. It is user contact.
