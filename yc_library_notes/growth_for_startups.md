# YC Startup Library Notes: Growth for Startups

## Core idea

Growth is not a grab bag of marketing tactics. It starts with a product users want, then focuses on the bottleneck in acquisition, activation, retention, monetization, or referral.

## Growth hierarchy

1. Pick the right metric.
2. Make sure users get value.
3. Fix activation/time-to-value.
4. Improve retention.
5. Add acquisition channels.
6. Scale what works.

## Channel questions

- Where do target users already congregate?
- What channel can the founders run manually now?
- What channel gives fast feedback?
- What channel matches the product's natural sharing behavior?
- Which channel is a distraction because it feels sophisticated?

## Office-hours warning

If retention is poor, growth work may only pour more users into a leaky bucket.
