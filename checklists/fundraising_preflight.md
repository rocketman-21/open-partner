# Fundraising Preflight Checklist

- [ ] One-sentence description is concrete.
- [ ] Market can plausibly be huge.
- [ ] Founder insight is clear.
- [ ] Product exists or evidence is strong.
- [ ] Key metric is meaningful.
- [ ] Growth/learning story is improving.
- [ ] Use of funds maps to milestone.
- [ ] Investor list is targeted.
- [ ] Plan B exists if fundraising fails.
- [ ] Default-alive/dead status is known.
