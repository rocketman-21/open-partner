# Pre-Launch Checklist

## Product

- [ ] A real user can reach the core value moment.
- [ ] The founder knows how to manually help users if onboarding fails.
- [ ] The product is narrow enough for a specific segment.
- [ ] There is a clear feedback channel.

## Users

- [ ] Target segment is named.
- [ ] At least 10 specific target users are listed.
- [ ] Outreach message is written.
- [ ] Founder will personally follow up.

## Metrics

- [ ] Activation metric defined.
- [ ] Retention/repeat usage metric defined.
- [ ] Success/failure threshold defined.

## Anti-theater

- [ ] Launch is not dependent on press.
- [ ] Launch is not delayed for polish unless there is real risk.
- [ ] Founder knows what will be learned within 7 days.
