# Office-Hours Preflight Checklist

Before the session, make sure you can answer these without hand-waving.

## Facts

- [ ] What did we commit to last session?
- [ ] Did we do it? What happened?
- [ ] What changed since last time?
- [ ] What shipped?
- [ ] Who exactly did we talk to?
- [ ] What did users do, not just say?
- [ ] What did the key metric do week over week?
- [ ] What is revenue or paid commitment status?
- [ ] What is retention or repeated core action?
- [ ] How much runway do we have?
- [ ] Are we default alive or default dead?

## Diagnosis

- [ ] What do we think the biggest current risk is?
- [ ] What evidence supports that diagnosis?
- [ ] What alternative diagnosis might be more painful but more true?
- [ ] What action are we avoiding?
- [ ] What are we tempted to work on that probably does not matter this week?

## Source routing

- [ ] I checked `office_hours_corpus_map.md`.
- [ ] I checked `sources/pg_yc_office_hours_source_matrix.md`.
- [ ] I can name 3-7 source anchors for the session.
- [ ] I can explain why each source is relevant.

## Output readiness

- [ ] We can leave with one or two actions due in 2-7 days.
- [ ] Each action has owner, deadline, metric, expected result, and failure signal.
- [ ] The stop-list is explicit.
- [ ] Next session's first question is defined.
