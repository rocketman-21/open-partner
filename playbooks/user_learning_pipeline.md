# User Learning Pipeline

## Goal

Convert user contact into better product, positioning, and growth.

## Pipeline

### 1. Define the segment

Be specific:

- Role
- Company/community type
- Current workflow
- Pain intensity
- Ability to pay/adopt
- Access path

### 2. Recruit users manually

Sources:

- Existing network
- Cold email/DM
- Communities/forums
- Competitor users
- YC-like peer groups
- Customer referrals
- Events/meetups

### 3. Ask about reality, not hypotheticals

Good questions:

- What do you do today?
- When did this last happen?
- What did you try?
- What was painful/expensive/risky?
- Who else is involved?
- What happens if you do nothing?
- What would make you switch?

Weak questions:

- Would you use this?
- Would you pay for this?
- Do you like our idea?

### 4. Extract signals

Look for:

- Repeated pain patterns
- Workarounds
- Urgency
- Budget/control
- Emotional intensity
- Existing spend
- Requests for access
- Follow-up behavior

### 5. Update product/growth

After every 5-10 conversations, decide:

- Change ICP?
- Change value proposition?
- Change onboarding?
- Build/remove feature?
- Change pricing?
- Narrow market?
- Stop pursuing this idea?
