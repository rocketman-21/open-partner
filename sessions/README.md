# Session Ledger

One file per office-hours session: `YYYY-MM-DD-<company>.md`, written from
`templates/session-summary.md` before the session ends.

This ledger IS the accountability loop. Every session starts by opening the most
recent entry and scoring its commitments — DONE / PARTIAL / NOT DONE — before any
narrative. Work done instead of a commitment scores it NOT DONE, no matter how
good the substitute was. A commitment missed twice gets shrunk until it cannot
fail, never silently re-assigned.

If a session ends without writing an entry here, the next session starts blind
and the loop is broken.
